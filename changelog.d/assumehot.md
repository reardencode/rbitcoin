- **`--hot-digest` and `--assumehot` start a node from another node's store.** `--hot-digest` prints `network height tiphash digest` for a store. The digest covers the confirmed chain and its spend state, by height, so it does not depend on `store.secret`, a migration from schema 24, orphans or reorg history. `--assumehot-from DATADIR --assumehot HASH` imports a complete, cleanly stopped, unpruned, current-schema source into an empty `store/`. Neither store may be split with `--datadir-cold`, and neither datadir may sit inside the other. It holds the source's lock, never writes to the source's store (a copy cut short is refused, not trimmed), checks each header and body, and connects each block with IBD's checks (scripts are not run). It recomputes spends, fees and indexes in `store.import/` (the scripthash index only with `--sh-index`) and renames that to `store/` only when the digest matches. Both walks log progress every 10 seconds, and the import also shows on `GET /progress` with `--health-listen`. A later start with the same flags opens the imported store without the source; another digest is refused. Both flags are CLI only. See `docs/operator/storage.md`.
