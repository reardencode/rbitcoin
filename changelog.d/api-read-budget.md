- **API store reads share one budget.** RPC, REST, Electrum, Esplora, and BlindBit take permits from one semaphore. The default is 1 when `--datadir-hdd` is set and `--store-read-budget` is omitted, otherwise one less than the core count (minimum 1). `--store-read-budget N` / `store_read_budget=` overrides that, including on rotating media. `--datadir-hdd` selects 1 only when the budget flag is omitted or `0`. Esplora's in-flight cap and the RPC work queue are queues in front of this budget. A full RPC work queue is still HTTP 503 before any call in that POST runs, and before a long-poll's tip poll. After a long-poll, the next call in that POST waits for a work-queue slot. A long-poll does not hold a disk permit while it waits. A `getblocktemplate` without a `longpollid` is not a long-poll: it keeps the work-queue slot. The build reads the template tip on `rbtc-off-pool` with no disk permit, takes one permit, and reads the tip again without waiting on connect. It builds only when both reads match. A long-poll's wait still samples off the permit. Esplora `GET /block-template` uses the same build read, before its 15-second cache lock. The cache TTL is unchanged.
