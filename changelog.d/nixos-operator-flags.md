- **The NixOS module accepts the operator flags.** Peering, mempool, permission, index, RPC, signet, and notify settings are `services.rbitcoin` options. `p2p.maxInbound` defaults to 200 and omits `--max-inbound` at that value. `esplora.hiddenService = false` passes `--esplora-onion=0` when Tor control is on. `netPermissionBind` requires `p2p.listen`, is refused with `trustPeer`, and its port is opened when `p2p.openFirewall` is set. `rpc.tokenFile` and `rpc.workQueue` require an RPC listener. `esplora.hiddenService` requires `esplora.enable`. `electrum.hiddenService` requires `electrum.enable`. When an onion flag implies Tor control, the module enables `services.tor`, listens on `127.0.0.1:9051`, and writes a group-readable cookie at `/run/tor/control.authcookie`. A custom cookie must be a file in `/run/tor` or `/var/lib/tor`, because the tor unit cannot write anywhere else. The `tor` group uses the NixOS tor gid. `p2p.listenOnion` requires `p2p.maxInbound` above 0. `apiLog` outside the datadir is writable. A log, token, or socket file directly in `/` is refused. `esplora.blockTemplate` and `esplora.socketPath` require `esplora.enable`. `ExecStart` writes each `%` as `%%`, so systemd leaves `%s` in `alertNotify` and `startupNotify` for the node. `extraArgs` remains for `--conf`, test knobs, and secrets that must stay off argv.
